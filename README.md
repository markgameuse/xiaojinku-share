# 小金庫

給自己用的記帳 App，Windows 和 Android 都有。收支、帳戶、信用卡、股票（台股和美股）都能記，資料存在自己的裝置上，也可以用自己的 Google 雲端硬碟在手機和電腦之間同步，或在自己的 Supabase 建一個免費專案，同步得更快。

## 下載

到 [Releases](https://github.com/markgameuse/xiaojinku-share/releases/latest) 下載最新版：

- Windows：`xiaojinku-setup-版本.exe`
- Android：`xiaojinku-版本.apk`

之後有新版時，App 會自動提示。

## 隱私權

資料存在你自己的裝置、你自己的 Google 雲端硬碟，或你自己的 Supabase，開發者看不到。詳見 [隱私權說明](PRIVACY.md)。
